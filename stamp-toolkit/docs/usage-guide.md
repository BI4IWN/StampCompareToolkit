# 印章对比工具 · 使用说明与技巧

> 正式桌面版为 **Tauri + Rust** 内核（macOS / Windows），网页版同源。界面三栏：左边工具栏与画布、右边「判定 / 识别 / 候选」检查器、底部状态栏显示进度。
> 这份说明只讲怎么用、怎么用好；不记录版本变化。

## 一、三分钟上手

1. **放两张章**：拖入 / `⌘V` 粘贴 / 「选择文件…」到左边「参考章」，右边「待验章」。桌面版 `⌘⇧S` 截图后直接粘贴最快。
2. **自动出结果**：放进去就自动提取（红章默认按红度取墨）。要么保持默认，要么按第二章"看情况开关"。
3. **对齐**：点 `⚡ 自动对齐`（`A`）。不理想再用滚轮微调或滑块。
4. **看结论**：右侧「判定」给相似度与文字 / 几何 / 编码三项指标；想看差在哪就开「差异高亮」。

> 小贴士：一次只比"同一位置的两枚章"。跨页比对会带上不同的正文背景，相似度必然偏低。

## 二、按情况选功能

| 你手上的情况 | 该用什么 | 说明 |
|---|---|---|
| 红章、白底、印得清楚 | 什么都不用点 | 自动提取已够用，直接对齐比对 |
| 灰底扫描件，字边一圈深、字心发灰（晕染） | 工具栏「优化提取·开」 | 改按"深×艳"取墨，抑制边缘环；比完记得关回去 |
| 淡章、残章，笔画细、提出来断断续续 | 「优化提取·关」+ 取色 | 默认关就是为这种章；开着反而把淡笔画切碎 |
| 蓝/紫/黑/灰章，或多种颜色混盖 | 原图 → `💧 点选取色` | 每个颜色点一处，深浅各取一次 |
| 背景表格线、签名、正文被一起提进来 | 取色面板 `⊘ 排除` 后点它 | 排除优先于提取；「剔除容差」调小更精准 |
| 必须和某个具体色值严格一致（专色、防伪油墨） | 查看器底部「匹配 → 精确RGB」 | 只认容差内的欧氏距离；色相模式会把相近深浅一起抓 |
| 盖章压扁、拍歪，章呈椭圆 | 工具栏「圆章校正·开」（默认开） | 拟合长短轴拉回正圆；淡墨或残章会自动跳过，不会拧出波纹 |
| 只要章的某一块（避开正文压字、章外有签名表格） | 原图 → `◯ 圆形裁切` | 椭圆骨架 + 16 个控制点，拖任一点只动它自己；右侧实时预览，应用后按边界归一成正圆 |
| 差一点点对不上 | 滚轮旋转 + 滑块微调 + 「差异高亮」 | 画布内滚轮＝旋转，`Ctrl/⌘`+滚轮＝缩放 |
| 要确认公司名 / 编码 / 类型 | 「🤖 AI 识别」或「全部识别」 | 本地 OCR 先出结果，AI 复核；AI 失败会保留本地结果并写原因 |

## 三、提取不干净怎么办（五级处理）

按顺序加码，前一级够用就停：

1. **先调容差**：取色面板的「剔除容差」往小调，往往比反复取色更有效。
2. **再排除污染**：点「⊘ 排除」，去点背景线、签名、正文黑字——排除优先于提取。
3. **补取缺的墨**：章有深浅两段色，就分别点取深、浅两处；一次点不准就多点两三处。
4. **换匹配方式**：颜色杂乱时切「精确RGB」，只认你点的那个色值。
5. **还不行就圈定范围**：用「圆形裁切」或「框选区域」把正文压字切掉，再提取。

> 小贴士：取完色用「颜色加深」把淡墨提亮一档再比对，能明显改善浅章的相似度；但别开过头，笔画会糊成一片。

## 四、取色技巧

- **点笔画中段，不要点边缘**：边缘是过渡色，会把一圈抗锯齿像素一起取进去（这也是晕染的来源）。
- **同一种墨点 2–3 处**：扫描件同一枚章的墨色有深浅差，多点几处比调容差更稳。
- **深浅各取一次**：深色笔画 + 浅色笔画各一个色块，覆盖最完整。
- **取错了直接改用途**：同一个颜色再点一次会切换「提取 / 排除」，以最后一次为准，不用删了重加。
- **放大镜是 5.5×**：悬停即可看像素和 hex 值，点下去之前先确认这里确实是墨。
- **取色标记**：取过的地方会留一个小圆点（排除色带斜杠），方便回看取过哪里。

### 圆形裁切技巧（3.6.28）
- 打开「原图 → 圆形裁切」：**椭圆是骨架**（8 个方块手柄改整体大小/位置），另有 **16 个控制点**，拖任一点只动它自己，别的点不动。
- 动过控制点后曲线变绿，那就是真正会被裁下来的边界；**右侧同时按这条边界实时预览**（拖动时 120ms 内跟随），所见即应用结果。
- 应用时按你的边界做**径向归一**：边界上的笔画正好落在圆周，不会留一圈白边，边界外的正文/签名/表格线全部丢弃。
- 空白处点一下＝放弃当前选择重新开始（不用先点取消）；拖出新圆后仍可继续微调。
- `Alt/⌘` + 点控制点＝删点（至少保留 6 个）；方向键仍可微调整体框。
- 只想裁掉章外杂物、章本身是正圆时，直接拖出椭圆、四个轴端手柄贴边即可，不必动控制点。
- 裁完如果还想调颜色，关掉查看器后用「点选取色」继续，两者互不覆盖。

### 剔除技巧（把正文、背景、签名清掉）

- **先看匹配模式**：默认「色相」适合剔掉"同类但深浅不一"的一整片（比如浅粉底纹）；只想剔掉某个精确色（防伪油墨、印刷网点）就切「**精确RGB**」。
- **容差就是"剔多少"**：色相模式下 4% ≈ ±8° 色相窗，40% ≈ ±22°；精确RGB 下容差按颜色距离放大（39% ≈ 46.8）。**先小后大**，一点一点加，别一上来拉满——拉满等于把整枚章一起剔掉。
- **点重复色不会白点**：同一个颜色再点一次，会按**当前容差和当前匹配模式**重新算一遍，状态栏直接告诉你「该色命中 N 像素」——所以"调完容差再点同色"就是最快的调参方式。
- **命中 0 像素说明这个色不存在**：状态栏会说「未命中任何像素」，换一处笔画取色，或换匹配模式；这时别继续加同一个色。
- **排除优先于提取**：同一像素既满足提取又满足排除时，按排除处理。所以别把章的主色加进排除列表。
- **剔不干净的分层来**：先剔最大片的底色 → 再剔正文黑字 → 最后剔签名；每剔一层看一眼提取结果，避免叠加过头。
- **剔错了用「停用」而不是删**：chip 上点「停用」暂时不起作用，保留色值方便再调；删掉就得重新取色。
- **圆形裁切专治"章外的东西"**：正文压章、背景有格子、签名压边，用「圆形裁切」把区域框住比剔颜色更干净（见第五章）。
- **颜色条上限 40 个**：点第 41 个会提示，先删掉不用的再加。
- **深色章**：先点一处最深的地方，再点一处中间的灰度，两色叠加通常一次成型。

## 五、圆章校正与拉正

- 默认开启。它会拟合章的椭圆长短轴，把压扁的章拉回正圆，同时把尺寸归一，便于和另一枚章叠比。
- **会自动跳过的情况**：墨迹太淡、残缺过多（覆盖太低）、本来就是近似正圆（≥0.93）。跳过时不改几何，避免把淡章拧出波纹。
- **想知道有没有校正过**：状态栏会写明旋转角度、缩放比例与校正前后的轴比。
- **手动兜底**：校正后还不正，用「圆形裁切」按章的外缘圈一个圆，应用后即为正圆；或者用滑块/滚轮手动拉。
- 若发现某枚章被"越拉越歪"，把「圆章校正」关掉再比，说明这枚章的形状不适合自动校正。

## 六、对齐与判定怎么看

- **先自动、再手调**：`⚡ 自动对齐` 会先找最优旋转/缩放/平移；手调只做最后 ±2° 的微调。
- **叠加 / 滑块 / 并排**：叠加看整体重合，滑块左右拉看细节，并排看两枚章各自的边缘。
- **差异高亮**：红/绿分别表示"只有这枚有"的墨迹，集中在边缘说明是扫描噪声，成片错位说明真的不一致。
- **三项指标**（缺数据显示「—」）：
- **文字**：两枚章的机构名相似度，同一枚章应接近 100%，不同章通常掉到 30% 以下。
- **几何**：椭圆轴比与外形一致性，用来判断是不是"同一个章型"；不同章常见 0%。
- **编码**：防伪码 / 编号是否一致，没有编码就显示「—」。
- **判定标签**：相似度与三项指标会合成为「通过 / 可疑 / 不一致」，可疑通常意味着"形状像、文字差一点"，值得人工再看一眼。

## 七、AI 识别技巧

- **先本地、后 AI**：点识别会先用本地 OCR 出结果（约 1 秒），再让 AI 复核；AI 超时或报错时不会清空本地结果，只会在面板写明原因。
- **⚡快速 / 🎯精确**：快速关闭模型思考，一般 1 秒内出结果，适合清晰章；精确更慢但抗模糊、抗旋转。
- **图越干净越准**：先在取色面板把背景和正文排除掉，AI 看到的是白底章面，识别率显著提高。
- **失败怎么读**：面板与状态栏会写具体原因——`未返回可解析的 JSON` 多半是模型/端点不匹配；`401` 是 key 无效；`限流` 是调用太频繁，隔几秒重试即可。
- **纯文本模型**：只支持文本的模型请把「提取方式」切到「文本解析」，让它读本地 OCR 的粗文字而不是看图。
- **多套配置互不干扰**：每个服务商各存各的地址/模型/Key，切换预设会自动回填，不会串。
- **配置框不会误关**：点遮罩或别处不会关闭，只有「保存 / 关闭」两个按钮能退出，避免填一半丢内容。
- **不用的配置可以删**：点「清除此配置」→ 确认后只删当前服务商的保存项（Key、模型、地址），换服务商或换电脑前先清掉。

## 八、印章库与截图

- **存库**：比对满意的章点「存参考章 / 存待验章」进库，下次在「印章库」里一键载入；库里的章可改名、删除，按名称/备注/识别文字搜索。
- **改保存路径**：印章库 →「更改保存路径」，之后新存的章都在新目录（老文件不会被搬走）。
- **截图**：桌面版 `⌘⇧S`（可在设置里改）框选屏幕区域，截完自动进剪贴板；设置里可选"截完直接贴到参考章/待验章"。

## 十、症状速查

| 症状 | 三步处置 |
|---|---|
| 提出来只有外轮廓、字心发空 | 开「优化提取」→ 仍空就用取色补一处深色 → 还不行切精确RGB |
| 提出来带了一圈正文/表格线 | 用「⊘ 排除」点它 → 剔除容差调小 → 再不行用圆形裁切圈定 |
| 取色后图里冒出另一枚章 | 说明取到了背景色，删掉那个颜色；先把正文排除再取色 |
| 剔除之后颜色加不上 | 检查是不是剔到了笔画主色（列表里带红色圆点的），删掉那条再提取 |
| 章是歪的 / 椭圆的 | 开「圆章校正」→ 关掉看是否更差 → 用圆形裁切手动圈正 |
| 相似度只有个位数 | 检查两枚章是不是同一枚、有没有对齐；看差异高亮是不是整体错位 |
| AI 一直失败 | 看面板写的原因 → 换「文本解析」→ 检查 key 与模型名是否匹配 |
| 取色时鼠标发飘 | 关掉「差异高亮」和「颜色加深」再取色，取完再开 |
| 存库后日期显示「—」 | 文件没有创建时间，属于正常兜底；不影响载入比对 |
| 圆形裁切右侧和左边边界对不上 | 3.6.28 已按边界径向归一；若仍不一致，确认是不是把控制点拖出了图片范围，或先点空白重画一次 |
| 圆形裁切后章边还有一圈白 | 边界比章环大了一点：把控制点往里收 2–3px 再应用；或直接拖椭圆手柄贴边 |

> 隐私说明：印章图片与识别结果默认只在本机处理；只有你主动点「AI 识别」时，当前章的图才会发给你配置的 AI 服务，密钥只保存在本机。
