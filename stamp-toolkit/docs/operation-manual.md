## 一、启动与访问

### 一键启动（推荐）

- **macOS**：双击 `启动印章对比工具.command` 即可运行。`.command` 扩展名会被 macOS 自动用「终端」打开，双击即启动，无需任何额外设置。
- **Windows**：双击 `launcher.bat`。

> 注意：macOS 上直接双击 `launcher.sh` 时，部分系统会默认用文本编辑器打开（.sh 被关联到文本编辑），这是系统行为而非文件损坏。此时请改用 `启动印章对比工具.command`，或右键 `launcher.sh` → 打开方式 → 终端.app。

启动器会自动检测运行环境、安装缺失依赖、启动服务并打开浏览器。启动过程中终端窗口会显示进度信息，首次运行需要安装 PaddlePaddle（约 700MB），请耐心等待。服务就绪后浏览器会自动打开工具页面。

停止服务：macOS/Linux 按 `Ctrl+C` 或关闭终端窗口；Windows 关闭命令行窗口即可。

> 常用参数（终端手动运行）：`./launcher.sh --port 9000` 更换端口；`./launcher.sh --no-install` 跳过依赖安装；`./launcher.sh --no-browser` 不自动打开浏览器；`python3 stamp_app.py --no-ocr` 跳过 OCR 模型加载、启动更快（仅使用对比/导出功能）。
>
> **依赖安装（PEP 668 说明）**：现代 macOS（Homebrew）/ Ubuntu / uv 管理的 Python 属于"外部管理环境"，直接执行 `pip install` 会报 `externally-managed-environment` 错误。启动器已自动处理：① 优先使用**已装好依赖的 Python**（例如系统自带的 Python 3.9 已装好 PaddleOCR 时会直接使用，无需任何安装）；② 否则在 `src/.venv` 创建项目虚拟环境并把依赖安装到其中（标准 venv → uv venv → 无 pip 模式逐级兜底）；③ 并优先选择 PaddlePaddle 兼容的 Python 3.8–3.13（同时装有 3.14 与 3.9 时自动使用 3.9）。

### 直接打开 HTML

如果不需要 OCR 功能，可以直接用浏览器打开 `stamp-compare.html` 文件。此时印章对比、差异高亮、导出等功能均可正常使用，仅 OCR 文字识别不可用。

### 访问地址

通过启动器启动后，工具运行在 `http://127.0.0.1:8765/`。如需更换端口，命令行启动时添加 `--port` 参数：

```bash
python3 stamp_app.py --port 9000
```

## 二、界面总览

工具界面从上到下分为以下区域：

**顶部标题栏**：显示工具名称和简要说明。

**图片加载区**：左右两个虚线框，左侧为"参考章"（已知正确的印章），右侧为"待验章"（需要核验的印章）。每个区域支持三种输入方式。

**提取结果条**：图片加载后，两个提取结果缩略图并排显示在加载区下方，展示自动提取的印章图像。**每个提取区上方各有一块墨色面板**（参考章/待验章独立）：预设红/蓝/紫多选、💧 手工取色、自定义色芯片展示与剔除。每个缩略图下方显示 OCR 识别结果（名称、编码、类型）。

**工具栏**：两行控制条。第一行包含操作目标切换（参考章/待验章）、对比模式选择（叠加/滑块/并排）、自动对齐、差异高亮、放大镜、导出、报告、印章核实、全部识别按钮。第二行包含透明度、缩放（含等比/水平/垂直轴选择）、水平偏移、垂直偏移滑块，以及重置按钮。（墨色选择已移至提取结果条中每枚印章上方的独立面板。）

**旋转控制条**：紧贴对比区域上方，提供旋转角度滑块（-180° 到 180°，步进 0.1°）。

**对比区域**：中央大尺寸画布，显示两枚印章的对比画面。白色背景配灰色网格和十字参考线。**加载第一枚印章后即显示**：单枚时按原色清晰呈现提取结果，可先行人工查验；两枚齐全后自动进入叠加对比。

**状态栏**：显示当前操作提示和反馈信息。

**快捷键提示条**：对比区域下方显示可用快捷键。

## 三、加载印章图片

每个印章位置（参考章 / 待验章）支持以下三种加载方式：

### 粘贴

在工具页面获得焦点的状态下，按 `Ctrl+V`（macOS 为 `Cmd+V`）粘贴剪贴板中的图片。如果两个位置都尚未加载，会弹出选择对话框让你指定粘贴到"参考章"还是"待验章"；如果只有一个位置为空，则自动填入空位。

### 拖拽

将图片文件从文件管理器或桌面直接拖入对应的虚线框区域。

### 点击上传

点击虚线框区域会弹出文件选择对话框，选择图片文件后自动加载。

### 支持的图片格式

支持浏览器能解码的所有常见图片格式：PNG、JPEG、BMP、WebP 等。

### 移除图片

每个已加载的图片区域右上角会出现一个删除按钮（×），点击即可移除该印章并清空相关数据。

### 替换图片

对已加载印章的位置重新执行粘贴、拖拽或上传操作，即可替换为新图片。

## 四、印章自动提取

图片加载后，工具会自动执行印章提取流程：

1. **墨色检测**：扫描图片所有像素，通过 HSV 色彩空间判断是否属于选中墨色（可多选并集）。默认仅红章：红色色相范围为 0°-40° 和 320°-360°（含橙红、紫红）；可选蓝色 180°-265°、紫色 250°-330°
2. **形态学膨胀**：将检测到的墨色区域进行膨胀操作，连接断裂的笔画
3. **连通域分析**：识别图中独立的印章区域（最多保留 3 个候选，见"多印章候选切换"）
4. **质心与圆度计算**：计算每个印章区域的质心；圆度采用双通道判定——边界框宽高比接近 1，或墨迹距离分布呈环形（半数墨迹位于 p97 半径外半段），后者使**圆环有缺口/断笔的残缺圆章**也能正确识别
5. **裁剪与归一化**：以质心为中心裁剪印章区域，缩放到 **1200×1200 像素**高分辨率标准尺寸，保持墨迹清晰
6. **透明度映射**：根据像素的"墨色程度"生成透明度通道，使非印章区域自然淡出，并按墨色微调对应色彩通道
7. **噪声去除**：通过 BFS 连通域分析，移除面积小于 20 像素的噪点

### 圆形章与异形章

工具自动判断印章形状。当宽高差小于 18% 时判定为圆形章，否则为异形章（如椭圆章、方章）。两种类型均可正常对比，但圆形章的 OCR 识别效果更佳。

### 提取结果

提取完成后，两个印章的缩略图显示在"提取结果条"中，背景透明，边缘干净。**点击缩略图循环放大 1× → 2× → 3× → 4×**，便于查看提取细节。

## 五、墨色选择（每枚印章独立，含颜色排除，v2.5.0）

参考章与待验章**各有独立的墨色面板**，位于提取结果条中各自提取缩略图的**上方**（面板标题为"参考章墨色"/"待验章墨色"）。两枚印章的墨色选择互不影响：例如参考章按红章提取、待验章按蓝章 + 自定义绿章提取，可同时生效。

每个墨色面板包含三部分：

### 预设色多选（默认红章）

- **红章**（默认）：最常见的公章、财务章等红色印油
- **蓝章**：部分业务章、外资企业章使用的蓝色墨水
- **紫章**：紫色/紫红色印油的印章

点击芯片即可切换选中状态（可同时选中多种，取并集检测）；至少保留一种墨色，最后一种不可取消。切换后**该印章**会自动重新提取，无需重新上传图片。

### 💧 手工取色（提取 / 排除两种，支持多种）

> **手工取色覆盖默认墨色**：首次点选手工颜色（提取或排除）时，会自动取消默认红章，之后仅按手工选择的颜色提取；如需保留某预设色，可在取色后重新点选该预设芯片。

预设色之外的墨水颜色（如绿色、橙色、黑色印油，或偏色严重的红章），可以通过手工取色处理：

1. 点击对应面板的「💧 提取」按钮进入**提取取色**模式，或「⊘ 排除」按钮进入**排除取色**模式（按钮高亮）
2. 鼠标移到该印章的**原图预览**上（注意：不是对比区域），会显示**带 4× 放大视图的取色放大镜**（含十字准线）与颜色色块、色相信息，并提示"提取 / 排除"
3. 在印章墨迹处点击，即添加一种自选色；**可连续点选多种颜色**（混合墨色场景逐一点选，均以色点芯片展示在面板中）
4. 再次点击当前按钮、点击另一枚印章的取色按钮（切换目标）或按 `Esc` 退出取色模式

### 颜色排除（v2.5.0 新增）

- 「⊘ 排除」取色得到的颜色会被标记为**排除色**（芯片显示红色"排除"标签，色点上带斜线）
- **排除色优先**：印章提取时，命中所选排除色的像素会被**剔除**（不参与提取），用于去除背景色、或误捕捉进来的其他颜色（如单据上的红色边框、图章旁的同色文字）
- 每个自选色芯片都可点击「提取 / 排除」标签**随时切换**两种模式，切换后立即重新提取

### 自选色展示、剔除与启停

- 每个自选色以芯片形式显示在对应面板中，**芯片上的色点直观展示所选颜色**（排除色带红色斜线）
- 点击芯片：临时**启用 / 停用**该颜色（停用后该颜色不再参与提取，色点变淡）
- 点击芯片上的 **×**：从该印章的列表中**剔除**该颜色（永久移除）
- 预设色与自选色均可全部清空，仅保留任意一组；全部清空时自动回退红章

> 提示：
> - 混合盖章场景（如发票上同时有红色发票专用章和蓝色业务章）可在同一面板同时勾选红+蓝一次提取
> - 参考章与待验章墨色不同（如红章 vs 蓝章）时，两枚印章可分别设置，互不干扰
> - 提取结果中混入了不需要的墨色时，取消勾选对应芯片或剔除自选色即可排除
> - 蓝章照片在默认红章模式下会提取为空，请在对应面板勾选蓝章后重新提取
> - **任何墨色改动都会自动按新选择重新提取对应的印章**，无需重新上传图片；OCR 识别也会使用该印章自己的墨色选择

## 六、多印章候选切换

当一张图片中检测到多个独立的印章区域时（例如单据上同时盖有公章和财务章），提取结果条中对应的缩略图下方会出现候选切换芯片（"印章 1""印章 2""印章 3"），按面积从大到小排列。

- 点击芯片可切换提取对应的印章，切换后该印章的调整参数自动重置，OCR 也会自动重新识别
- 当前选中的芯片高亮显示
- 只有一个印章时不显示芯片

## 七、对比模式

工具提供三种对比模式，可通过工具栏按钮或快捷键切换：

### 叠加模式（快捷键 `1`）

两枚印章以半透明方式叠加显示在同一位置。参考章叠加极浅蓝色调，待验章叠加极浅红色调，通过透明度滑块控制待验章的不透明度（默认 50%）。这种模式最直观，适合快速目视对比整体形状和文字布局。

### 滑块模式（快捷键 `2`）

对比区域被一条垂直分割线分为左右两部分，左侧显示参考章，右侧显示待验章。拖拽分割线可以实时调整分割位置。这种模式适合逐区域精细对比细节。

### 并排模式（快捷键 `3`）

两枚印章等大并列显示，中间以虚线分隔。适合整体外观和尺寸的直观比较。

## 八、自动对齐

点击工具栏的"⚡ 自动对齐"按钮或按 `A` 键，工具会自动计算待验章相对参考章的最佳对齐参数（旋转、等比缩放、水平/垂直偏移），并直接应用到待验章上。

自动对齐在后台完成，通常 1 秒内结束，完成后状态栏会显示对齐结果（旋转角度、缩放比例、偏移量）和对齐后的相似度。

### 算法原理

自动对齐分四步进行（详见技术文档）：

1. **质心对齐**：计算两枚印章墨迹质心，确定初始偏移
2. **半径归一**：按墨迹 RMS 半径之比确定初始缩放
3. **旋转估计**：将两枚印章的墨迹按角度投影为 360 桶直方图，通过圆相关找到最佳旋转角
4. **局部精调**：在初始解附近以墨迹重合度（IoU）为目标函数做网格搜索精调

### 使用建议

- 自动对齐以参考章的当前姿态为基准——如果你手动调整过参考章，对齐结果会保留你的调整
- 对齐后如需微调，可继续使用滑块、拖拽等手动方式
- 对于墨迹很少或严重残缺的印章，自动对齐可能失败，此时请手动对齐
- 对齐质量直接影响相似度数值，建议在开启差异高亮前先执行一次自动对齐

## 九、交互调整

为了精确对齐两枚印章，工具提供了丰富的交互调整功能。所有调整操作都作用于当前选中的"操作目标"（参考章或待验章，默认为待验章）。

### 切换操作目标

点击工具栏的"参考章"/"待验章"按钮，或按 `Tab` 键切换。当前选中的印章在对比区域会显示蓝色虚线边框和缩放手柄。

### 旋转

旋转控制条提供 -180° 到 180° 的旋转调节，步进 0.1°。也可以通过键盘左右方向键微调（每次 0.5°）。将鼠标悬停在旋转滑块上并滚动鼠标滚轮也可以精细调节。

旋转以对比区域画布的中心为圆心，而非印章图像自身的中心。

### 缩放

缩放范围 30% 到 200%，支持三种缩放轴模式：

- **等比**（默认）：水平和垂直同步缩放
- **水平**：仅调节水平方向缩放
- **垂直**：仅调节垂直方向缩放

通过键盘上下方向键可微调缩放（每次 1%）。鼠标在对比区域滚动滚轮也可以缩放。

### 偏移

水平偏移和垂直偏移滑块分别控制印章在水平和垂直方向的位移，范围 ±100 像素，步进 0.5 像素。

### 拖拽移动

在对比区域内直接按住鼠标拖拽印章，可以实时移动印章位置。拖拽采用亚像素累积算法，移动平滑无抖动。

### 缩放手柄

选中印章的四周和四角共 8 个手柄，拖拽手柄可以缩放印章：

- **四角手柄**（nw/ne/sw/se）：同时调节水平和垂直缩放
- **四边手柄**（n/s/e/w）：仅调节对应轴的缩放

手柄跟随印章旋转角度，光标方向也会随旋转自动调整。

### 重置

点击工具栏的 ↺ 按钮或按 `R` 键，将当前选中印章的旋转、缩放、偏移全部恢复为默认值。

## 十、差异高亮

点击工具栏的"差异高亮"按钮或按 `D` 键开启/关闭。仅在叠加模式下有效。

开启后，工具对两枚印章进行逐像素对比：

- **绿色半透明覆盖**：两枚印章吻合的区域
- **红色/橙色覆盖**：存在差异的区域，颜色深浅反映差异程度
- **纯红色**：仅在一枚印章中存在的区域（另一枚对应位置为空白）

对比区域右上角会显示"相似度: XX.X%"，绿色文字表示相似度高于 85%，红色文字表示低于 85%。

相似度计算方式：统计两枚印章都有内容（透明度 > 30）的像素中，颜色差异小于阈值（平均通道差 ≤ 20）的像素占比。

## 十一、放大镜

点击工具栏的 🔍 按钮开启/关闭放大镜功能。

开启后，鼠标在对比区域内移动时，鼠标指针附近会出现一个 150×150 像素的放大视图，4 倍放大倍率，并带有十字参考线辅助定位。适合检查印章边缘清晰度、文字笔画细节等微观差异。

## 十二、OCR 文字识别

### 前提条件

OCR 功能需要通过 `stamp_app.py` 启动后端服务。如果使用一键启动器（launcher.sh / launcher.bat），OCR 服务会自动启动。如果直接打开 HTML 文件，OCR 不可用，工具会在页面顶部显示"OCR 服务未连接"的提示。

> v2.0.0 起后端服务对 OCR 依赖做了容错：即使未安装 PaddlePaddle/PaddleOCR，服务仍会正常启动并提供页面与对比功能，状态条会明确提示"OCR 模型未加载"及安装命令。识别请求会返回具体的错误原因而不是静默失败。

### 使用方法

点击工具栏的"全部识别"按钮，工具会依次对参考章和待验章执行 OCR 识别。识别过程中会显示进度条和状态文字，可以点击"■ 中断"按钮取消当前识别。印章加载后（服务在线时）也会自动触发识别。

识别请求会携带当前勾选的墨色组合（红/蓝/紫多选 + 手工取色的自选色相 hues），后端据此提取对应墨色的文字区域。蓝色、紫色印章同样可以识别；手工取色的颜色（如绿色）也会参与后端印章区域检测与文字提取。

### 识别结果

识别完成后，结果内联显示在每个印章提取缩略图的下方，分为三行：

- **名称**：印章中的公司/机构名称（上弧文字）
- **编码**：印章下弧的编号
- **类型**：印章类型信息（如"合同专用章""财务专用章"等）

### 识别原理

后端使用 PaddleOCR 对印章进行极坐标展开和文字识别。具体流程：提取红色通道 → 极坐标展开上弧文字 → 多种参数组合二值化 → OCR 识别 → 取最优结果。整个过程约 15-30 秒。

### 已知局限

以下情况可能导致识别失败或结果不准确：

- 紫色等特殊墨色印章（v2.0.0 已支持红色与蓝色）
- 图片中存在多个重叠印章
- 印章模糊、残缺或拍摄角度严重倾斜
- 印章文字过于密集或过小

## 十三、导出对比结果与报告

### 导出 PNG（"导出"按钮）

点击工具栏的"导出"按钮，将当前对比画面保存为 PNG 图片。文件名格式为 `印章对比_YYYY-MM-DD.png`。

导出内容包括对比区域中显示的所有内容：两枚印章、差异高亮覆盖层（如果开启）、相似度百分比等。

### 导出对比报告（"报告"按钮，v2.0.0 新增）

点击工具栏的"报告"按钮，生成一份自包含的 HTML 对比报告并下载，文件名格式为 `印章对比报告_YYYYMMDD_HHMM.html`。报告内嵌全部图片数据，无需网络即可打开和归档，适合作为核验过程留痕。

报告内容包括：

- 参考章与待验章的提取图（含各自的调整参数）
- 当前对比画面截图与对比模式
- 像素相似度及评估结论（高度吻合 / 部分吻合 / 差异较大）
- 双方 OCR 识别结果对照表（名称、编码、类型）
- 印章形状（圆形章/异形章）
- 生成时间与工具版本
- 免责声明：结果仅供辅助参考，不构成司法鉴定结论

## 十六、常见问题

### 粘贴图片没有反应

确认浏览器页面已获得焦点（点击一下对比区域），然后再按 Ctrl+V / Cmd+V。部分浏览器在地址栏获得焦点时不会触发页面的粘贴事件。

### OCR 按钮灰色不可用

两种可能：

1. **OCR 服务未连接**：直接打开了 HTML 文件或服务未启动。macOS 请双击 `启动印章对比工具.command`（或终端运行 `./launcher.sh`），Windows 双击 `launcher.bat`。
2. **OCR 模型未加载**（状态条会显示"OCR 模型未加载"）：服务已启动但依赖未安装。运行 `pip install paddlepaddle paddleocr opencv-python` 后重启服务即可，期间对比、导出等其他功能不受影响。

### macOS 双击 launcher.sh 打开的是文本编辑器

这是系统将 .sh 文件关联到文本编辑所致，不是文件问题。解决办法（任选其一）：

1. 双击同目录下的 `启动印章对比工具.command`（推荐，.command 固定用「终端」打开）
2. 右键 `launcher.sh` → 打开方式 → 终端.app
3. 终端手动执行：`chmod +x launcher.sh && ./launcher.sh`

### 印章提取效果不好

确保上传的图片中印章区域清晰可见。默认提取红章；蓝章/紫章需在"墨色"中勾选对应颜色（可多选）后自动重新提取。残缺圆章（圆环有缺口）已可正确识别；如仍提取异常，可尝试只用单一墨色排除干扰。如果图片中印章很小，尽量放大原图后再上传。工具对模糊、褪色印章的提取效果有限。

### 差异高亮显示相似度很低

先确认两枚印章是否已精确对齐。推荐先点击"⚡ 自动对齐"（或按 `A` 键）自动完成对齐，再按需微调后开启差异高亮。未对齐的情况下相似度数值没有参考意义。

### 启动器报告端口被占用

如果之前异常退出，旧的服务进程可能仍在运行。启动器会提示是否终止旧进程，选择"是"即可。也可以手动查找并终止占用 8765 端口的进程。

### Windows 下双击 launcher.bat 闪退

确保 launcher.bat 文件的行尾格式为 CRLF（Windows 格式）。如果文件被转换为 LF 格式，Windows 命令解释器将无法正确解析。

### 启动器报错 "externally-managed-environment"（PEP 668）

这是 Homebrew / Ubuntu 新版 Python 的安全机制，禁止直接向系统 Python 安装包。

- **正常使用**：直接双击 `启动印章对比工具.command`（或运行 `./launcher.sh`）即可——启动器会自动创建 `src/.venv` 虚拟环境并把依赖安装到其中，全程无需手工处理。
- **若你手动执行 pip**：请先进入虚拟环境再安装：

  ```bash
  cd stamp-toolkit/src
  python3 -m venv .venv && source .venv/bin/activate
  pip install paddlepaddle paddleocr opencv-python
  ```

- 若启动器提示"虚拟环境创建失败"，说明系统缺少 venv 模块（Ubuntu 需 `sudo apt install python3-venv`）。
