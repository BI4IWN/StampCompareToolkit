## 一、能做什么

| 能力 | 说明 |
|---|---|
| 自动提取 | 按墨色（红 / 蓝 / 紫 / 黑灰）把印章从合同、扫描件里抠出来，去掉底色与正文 |
| 手工取色 / 剔除 | 提取结果不理想时，直接在原图上点选要的颜色；也可以点选「排除」把杂色去掉 |
| 淡色章 | 颜色很淡的章自动识别并补一条「淡墨」颜色，也可手动微调 |
| 颜色增强 | 淡色、浅粉章提升对比度与彩度，默认「自动」，可手动调 1–3 档 |
| 圆章校正 | 拍照/扫描造成的椭圆压扁，自动迭代拉回正圆（开关可关） |
| 对齐 | 以拟合圆心与半径对齐两枚章，也可手动旋转/缩放/平移/角点变形 |
| 比对 | 叠加 / 滑块 / 并排三种模式，逐像素差异高亮与相似度判定 |
| 识别 | 本地 RapidOCR + 印章库校验；可选 AI 视觉模型（DeepSeek / 智谱 / 火山方舟豆包 / 自定义） |
| 印章库 | 保存、检索、一键载入历史印章，文件名即名称 |
| 桌面增强 | 全局截图快捷键、印章库面板、原生窗口与设置 |

## 二、安装与启动

### 桌面版

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `StampCompareToolkit-<版本>-mac-arm64.dmg` | 推荐；支持可选安装本地视觉模型 |
| macOS（Intel） | `StampCompareToolkit-<版本>-mac-x64.dmg` | 本地视觉模型不可用，其余一致 |
| Windows（x64） | `StampCompareToolkit-<版本>-win-x64-setup.exe`（安装版）/ `-win-x64-portable.exe`（免安装） | 内置便携 Python 运行时与 RapidOCR |

- **无需安装 Python**：安装包内置便携运行时与 OCR 组件（RapidOCR + onnxruntime），离线可用。
- **首次打开较慢**：未签名的包会被系统安全扫描几十秒（仅首次）；OCR 模型在后台加载，状态栏显示「OCR 模型加载中」，约 10–30 秒后自动就绪。
  - macOS 提示「无法验证开发者」：右键应用 → 打开，或在「系统设置 → 隐私与安全性」里点「仍要打开」。
  - Windows SmartScreen：更多信息 → 仍要运行。
- **数据目录**：macOS `~/Library/Application Support/印章比对工具/`；Windows `%APPDATA%\印章比对工具\`（设置、识别引擎、印章库默认路径等）。

### 网页版

直接打开 `stamp-toolkit/src/stamp-compare.html` 即可使用提取、比对、导出；文字识别需要后端服务（`python3 stamp_app.py`，默认 `http://127.0.0.1:8765/`）。桌面功能入口（截图、印章库、设置）在网页环境下自动隐藏。

## 三、界面结构

```
┌──────────────────────────────────────────────────────────────┐
│ 页头：🔴 印章对比工具 v3.6.8 │ 识别[本地|AI] │ 截图 印章库 设置 │
├──────────────────────────────────────────────────────────────┤
│ 工具栏：参考章/待验章 · 叠加/滑块/并排 · ⚡自动对齐 · 差异高亮 · │
│        🔍 · 导出 · 印章核实 · 全部识别 · 🤖AI · 🖼原图 · 🗑清空 · │
│        💾存参考章 / 💾存待验章 · ⋯更多                          │
├───────────────────────────────────┬──────────────────────────┤
│ 画布（叠加/滑块/并排，可缩放旋转） │ 检查器：判定 / 识别 / 候选 │
├───────────────────────────────────┴──────────────────────────┤
│ 状态栏：进度与提示                      ⌨ 快捷键 · 📖 使用说明 │
└──────────────────────────────────────────────────────────────┘
```

- 画布右下角有浮动工具条（参考章/待验章、－/＋、↺/↻、⚡、⟲），不占布局、不挡内容。
- 窗口宽度 ≤1199px 时右侧检查器收成抽屉，点页头左侧「判定」或按 `⌘I` 展开。
- 「⋯ 更多」是第二排：圆章校正开关、识别引擎入口、旋转/透明度/缩放/偏移滑杆，以及两块墨色面板。
- 窄窗口下工具栏可横向滚动，「⋯ 更多」固定贴右。

## 四、快速上手（5 步）

1. **载入**：点「选择文件…」、把图片拖进来，或按 `⌘V` 粘贴到「参考章」「待验章」；桌面版可先截图再粘贴；也可从「📚 印章库」载入。
2. **提取**：默认自动提取红章；非红章点「⋯ 更多 → 💧 提取」在原图上点选颜色；杂色用「⊘ 排除」去掉。
3. **校正**：拍照变形的圆章保持「圆章校正」开启（默认开），系统会拉回正圆。
4. **对齐**：点「⚡ 自动对齐」，或用滑杆/滚轮/键盘微调。
5. **比对与导出**：切 叠加 / 滑块 / 并排 看结果，必要时开「差异高亮」看像素级差异，最后「导出」保存 PNG。

## 五、载入印章

| 方式 | 操作 |
|---|---|
| 选择文件 | 粘贴区里的「选择文件…」按钮，或工具栏「⋯ 更多」外的导入快捷键 `⌘O` |
| 拖入 | 把图片直接拖到参考章 / 待验章区域（虚线高亮表示可放下） |
| 粘贴 | 复制图片后按 `⌘V`，粘到当前操作目标 |
| 截图（桌面版） | `⌘⇧S` 选区截图 → 浮层选择「参考章 / 待验章 / 仅复制」→ 自动粘贴并提取 |
| 印章库 | 「📚 印章库」里搜索并一键载入到参考章或待验章 |

- **一张图多个印章**：载入后画布上方会出现「候选 1 / 候选 2…」芯片，点一下即切换提取目标（圆形章会标注「圆形章」）。
- 载入后自动执行：检测印章区域 → 提取 → 圆章校正 → 计算判定。状态栏会给出每一步的结果。

## 六、提取印章（墨色）

### 6.1 预设墨色

「⋯ 更多」里有两块面板（参考章墨色 / 待验章墨色），各含四个墨色芯片：

| 芯片 | 适用 |
|---|---|
| 红 | 常见红色公章（默认） |
| 蓝 | 蓝色印章、蓝色签章 |
| 紫 | 紫色/深蓝紫章 |
| 黑/灰 | 黑白扫描件、灰度章、传真件；选中后出现「黑度阈值」滑杆（30%–88%，默认 62%） |

- 「黑度阈值」越大收进的笔画越多，越小只留最深的笔画。正文与章同色时，宁可调低阈值保留章的结构。
- 阈值太低会把章内文字一并削掉，属正常取舍。

### 6.2 自动兜底

- **黑灰章**：红章提取几乎为空（墨量 < 40 像素）且原图彩色占比 < 1% 时，自动切到「黑/灰」并提示。
- **淡色章**：基础提取平均 alpha < 150 或墨量 < 0.4% 时，自动追加一条「淡墨」颜色，状态栏提示「检测到淡色印章，已自动提取淡墨 #xxxxxx」，颜色列表里可随时停用。

### 6.3 手工取色与剔除

- 「💧 提取」：点选什么颜色就提取什么颜色（取点附近 7×7 邻域里最像墨的像素）。
- 「⊘ 排除」：把点到的颜色从结果里删掉，适合去正文、表格线、签名。
- 浅色（近白）取色会额外做两道门：必须比 21×21 邻域底色更暗 6 个灰度以上，且饱和度/亮度落在所选颜色附近——避免把整片纸底一起收进来。
- 每次取色/剔除后立即重算，右侧「提取结果 · 实时」同步刷新，并显示墨量与增量。

### 6.4 颜色增强

- 位置：「⋯ 更多 → 颜色增强」，默认勾选「自动」，滑杆 1–3 档。
- 自动档按笔画平均 alpha 与彩度估算强度（约 1–2.6 倍）；淡章会自动压低到 ≤1.25 倍，避免增强过头导致边缘连片（即「晕染」）。
- 增强会同时提 alpha、提彩度并略压亮度；手动调档适合「章很淡但不想丢细节」的情况。

### 6.5 颜色列表

查看器底部的颜色条列出所有手工/自动颜色：

| 元素 | 作用 |
|---|---|
| 色块 + `提取/剔除` | 标注这条颜色是加墨还是去墨 |
| `#RRGGBB` | 取到的颜色值 |
| 停用 / 启用 | 临时关掉这条颜色，便于对比效果 |
| `✕` | 删除这条颜色 |

### 6.6 框选提取区域

章与本底颜色接近、或章外有大量同色内容时，用框选限定范围：工具栏「🖼 原图」→「框选区域」→ 在原图上拖框 →「应用框选」。框选会锁定提取区域（不再自动找章），可在查看器里反复调整，或点「重置框」恢复自动定位。

### 6.7 圆形遮罩

判定为圆形章时，提取结果会自动清掉外圈以外的像素（半径 ×1.06 的余量），避免把正文、表格线带进比对。

## 七、原图查看器与取色放大镜

工具栏「🖼 原图」打开查看器，左侧是原图，切到取色/框选时右侧同时显示「提取结果 · 实时」：

| 标签页 | 用途 |
|---|---|
| 查看 | 只读浏览：滚轮缩放、拖拽平移、`适应` 一键铺满 |
| 框选区域 | 拖出矩形限定提取范围；框内可拖动、8 个手柄可缩放；`方向键` 微调 1px（`⇧` 10px）、`Enter` 应用 |
| 点选取色 | 点原图加颜色、点右侧提取结果剔除颜色；顶部可切「提取 / 排除」；`Esc` 退出 |

- 顶部「参考章 / 待验章」可切换作用对象，两枚章各自独立。
- **放大镜**：取色模式下跟随光标显示 5.5× 局部放大 + 十字准线 + 实时色值，便于精确点选笔画而不是纸底。
- **剔除容差**（4%–40%，默认 14%）：越大，颜色相近的像素被一起去掉得越多。剔除大色块时调大，只想删细碎杂色时调小。
- 框选/取色都只影响当前章的提取，不会改动原图。

## 八、圆章校正（椭圆 → 正圆）

拍照、扫描会让圆形章变成椭圆，直接影响对齐与相似度。开启「⋯ 更多 → 圆章校正」（默认开）后：

1. 从提取结果的墨迹外缘取点，拟合外圈椭圆（二阶矩 + 离群点剔除）；
2. 按椭圆长短轴与倾角做仿射变换，把椭圆拉成正圆并居中，同时按画布归一化尺寸；
3. 单轮往往不够（粗边环、轻微透视），会**迭代 2–3 轮**，直到轴比 ≥0.988；
4. 状态栏显示「圆章校正 0.82→1.00」这样的前后轴比。

**不会强行变形的场景**（自动放弃，保留原样）：内点率 < 0.6、采样点 < 80、角度覆盖 < 60%、轴比 < 0.62、墨迹填充率 > 0.55，或校正后并没有更圆。这样可避免把整块正文当成章去拉圆（淡色章手动取色时尤其容易触发）。

异形章（椭圆章、方章、骑缝章）本就不该被拉成正圆，可以关掉该开关。

## 九、对齐

### 9.1 自动对齐（⚡ 或 `A`）

以「拟合外圈圆心 + 半径」为基准：把待验章的圆心平移重合、按半径比缩放、按外缘角度直方图找旋转角，再用环形带的加权重合度微调。环带只取 `0.55R–1.18R`，章外的正文、签名不会把对齐带偏。

状态栏会给出：`自动对齐完成：旋转 −8.5° · 缩放 99.1% · 偏移 (0,0)px · 相似度 81.7% · 圆章校正 0.82→1.00`。

### 9.2 手动微调

| 操作 | 方式 |
|---|---|
| 平移 | 画布上拖拽当前章 |
| 旋转 | 画布内横向滚轮（0.1°/步）；`⋯ 更多 → 旋转` 滑杆；`←/→`（0.1°）；浮动工具条 ↺/↻（1°） |
| 缩放 | 画布内纵向滚轮（0.2%/步）；`⋯ 更多 → 缩放`；`↑/↓`（0.1%）；工具条 －/＋ |
| 透明度 | `⋯ 更多 → 透明度`（叠加模式下待验章默认 50%） |
| 水平/垂直偏移 | `⋯ 更多 → 水平偏移 / 垂直偏移` |
| 角点变形 | 拖四角手柄改变四边形（适合轻微透视），按住 `⇧` 等比 |
| 调另一枚 | 按住 `Alt` 再用滚轮/方向键，无需切换目标 |
| 复位 | `R` 或工具条 ⟲ |

切换操作目标：工具栏「参考章 / 待验章」，或 `⌘1` / `⌘2`。

## 十、对比模式与差异高亮

| 模式 | 快捷键 | 说明 |
|---|---|---|
| 叠加 | `1` | 两章叠在一起，用透明度/颜色观察笔画是否重合（默认） |
| 滑块 | `2` | 左右拖动分割线，逐块对比 |
| 并排 | `3` | 左右并排，等比例显示 |

「差异高亮」（`D`）按提取后的墨迹做逐像素比较，只保留差异区域，便于定位「多一笔 / 少一笔」。

「印章核实」会打开全国印章查询平台（山东省公安厅「电子印章查询」），用来核对印章编码/名称与备案信息是否一致——它是外部网站，需要联网。

右栏「判定」卡给出相似度与等级：

| 相似度 | 判定 |
|---|---|
| ≥ 90% | 一致 |
| 75%–90% | 可疑 |
| < 75% | 不一致 |

> 当前 v0 判定**只基于墨迹重合度**；文字指标、几何指标、编码指标三行是预留位，接入后会参与综合评分。判定用于辅助，不代替人工结论。

## 十一、右侧检查器

| 卡片 | 内容 |
|---|---|
| 判定 | 等级徽标、相似度、墨迹重合度进度条，以及文字/几何/编码指标（预留） |
| 识别 | 两枚章各自的公司名称、来源徽标（库内匹配 / AI / 未识别）、置信度、类型、编码；两章名称不一致时给出「⚠ 两章名称不一致」 |
| 候选 | 两枚章各自的印章库 Top-3 候选（名称 + 相似度 + 「采用」按钮） |

- 点「采用」会用该候选名称覆盖当前识别结果（不改动图像）。
- 名称来源徽标能看出结果从哪来：`库内匹配` 表示命中印章库，`AI` 表示来自视觉模型，未识别则为灰色。

## 十二、文字识别（本地 / AI）

### 12.1 两种识别方式

页头「识别」开关切换：

| 方式 | 说明 |
|---|---|
| 本地 | RapidOCR 识别环形文字 + 印章库 Top-3 校验；完全离线，不需要任何密钥 |
| AI | 调用配置好的视觉大模型识别；需要 API Key |

- 选择会被记住：**清空、重启后仍保持上次的选择**。
- AI 模式下载入印章会自动识别；两枚章各有独立识别按钮；点「全部识别」一次处理两枚。

### 12.2 本地识别

- 提取后按环形展开 → 行切分 → OCR → 文本归一化 → 与本地印章库比对。
- 命中足够可信时用库内名称（`库内匹配`），否则保留原始文本并提示需要复核（`needs_review`）。
- 状态栏会显示识别耗时；识别结果同时写入右栏与检查器。

### 12.3 AI 识别配置

点「🤖 AI」打开配置：服务商预设、API 地址、模型名称、API Key、提取方式（`文本解析` / `视觉识别`）。

| 预设 | 默认模型 | 说明 |
|---|---|---|
| DeepSeek | `deepseek-chat` | 纯文本模型，配合本地 OCR 文本做解析 |
| 智谱 AI | `glm-4v-flash` | 视觉模型，直接读图 |
| 火山方舟（豆包视觉） | `doubao-seed-2-1-pro-260915` | 视觉模型，约 3 秒返回 |
| 自定义 | — | 任意 OpenAI 兼容接口 |

- 配置保存在本机浏览器（localStorage），API Key 经本地后端代理转发，不写进代码库。
- 视觉模式会把印章图发给所选服务，请按自身合规要求选择是否启用。
- 视觉提示词已内置：先判断朝向（必要时转 180°）→ 裁出印章 → 沿圆周读字（必要时试 0°/90°/180°/270°）→ 读下缘编码与类型。
- 点「测试连接」可先验证地址与密钥，再「保存」。

## 十三、本地视觉模型（可选安装）

仅 **Apple Silicon** 且内存 ≥ 8GB 的 Mac 支持，不随安装包分发（模型约 700MB + 运行时约 830MB）：

1. 首次启动后探测硬件，若满足条件弹窗询问「是否为这台 Mac 启用本地识别」，选择「以后再说」则本版本内不再提示；
2. 选择安装后开始下载（12 段并发、可中断续传，断点保留分片）；
3. 「⋯ 更多 → 识别引擎…」里可随时查看/安装/取消/移除，也可「手动导入」已下载的模型目录；
4. 就绪后本地识别会优先走该模型；失败自动回退 RapidOCR，并在结果里标注 `fallback`。

不满足条件的机器（Windows、Intel Mac、内存不足）不会出现安装入口，功能照常使用 RapidOCR / AI。

## 十四、印章库

- **保存**：粘贴区下方「💾 保存参考章 / 保存待验章到印章库」，或库面板底部保存按钮。保存的是**印章原图**，下次载入时重新提取（因此不受当时提取参数影响）。
- **命名**：默认取识别出的公司名称，未识别则按 `印章_年月日_时分` 生成，保存前可改；名称即检索索引。重名会提示，可另存为 `名称_2`。
- **面板**：「📚 印章库」支持缩略图浏览、按名称/备注/OCR 名称搜索、一键载入到参考章或待验章、删除、打开目录。
- **自动索引**：直接往库目录里放 PNG/JPG（文件名当名称），打开面板或搜索时自动收录。
- **路径**：默认「文档/印章库」，可在设置或库面板里改。

## 十五、截图（桌面版）

1. `⌘⇧S`（Windows `Ctrl+Shift+S`，可在设置里录制修改）——全局生效，应用在后台也能触发；
2. 拖拽选区（多显示器可用，`Enter` / 双击 / ✓ 确认，`Esc` 取消）；
3. 自动复制到剪贴板并弹出浮层：粘贴到**参考章** / **待验章** / 仅复制；
4. 粘贴后自动执行提取与校正。

设置里可把「截图完成后」固定为某个目标，省掉每次选择。

## 十九、常见问题

**Q：状态栏一直显示「OCR 模型加载中」？**
首次启动需要 10–30 秒加载模型（后台线程，界面可用）。超过 1 分钟仍不动，检查是否把 `--no-ocr` 传给了后端，或在设置里切换 OCR 后端后重启。

**Q：红章提取出来是空白 / 只有零星像素？**
说明原图不是红色系。开「⋯ 更多」，用「💧 提取」在原图章面上点一下，或用「🖼 原图 → 点选取色」精确点笔画；黑白扫描件直接选「黑/灰」芯片。

**Q：淡色章提取后很淡、看不清？**
确认「颜色增强」是「自动」；不够就把滑杆往上调。若出现「晕染」（笔画边缘连成一片），说明增强过头，往下调 1–2 档，或把「剔除容差」调小。

**Q：取色后把正文也带进来了？**
近白色取色会把同亮度的正文边缘一起收进来。改用更接近笔画的颜色，或框选限定范围（「🖼 原图 → 框选区域」），再用「⊘ 排除」点掉正文。

**Q：拍照的圆章是椭圆，对齐总差一点？**
确认「圆章校正」开着，看状态栏是否显示 `0.xx→1.00`。若显示未校正，通常是章边不完整（被裁掉、被正文压住）——用框选把章完整框进来再试。

**Q：明明两边都是正圆，对齐还是偏？**
先看「判定」里相似度是否明显偏低；再确认两章的提取范围一致（有没有一侧多带了正文）。对齐基于拟合圆心与半径，提取范围不一致时圆心会偏。

**Q：识别结果和实际公司名差一两个字？**
本地识别依赖环形展开质量。可把「圆章校正」打开、用框选把章完整框进来，或切到 AI 识别；右栏「候选」里如果有正确名称，点「采用」即可覆盖。

**Q：AI 识别报「无法连接 AI 服务」？**
检查 API 地址是否为 OpenAI 兼容的 `/v1` 端点、Key 是否有效、模型名是否该服务商支持；点「测试连接」先验证再保存。

**Q：本地视觉模型装不上 / 按钮是灰的？**
仅 Apple Silicon 且内存足够的 Mac 会出现安装入口；Windows 与 Intel Mac 不提供（走 RapidOCR 或 AI）。下载中断后点「继续」会断点续传，不必重新开始。

**Q：清空后识别方式变了？**
不会。识别方式（本地/AI）会持久保存，清空与重启都保持上次选择。

**Q：Windows 上有什么不一样？**
本地视觉模型不可用；快捷键用 `Ctrl` 替代 `⌘`；数据目录在 `%APPDATA%\印章比对工具\`。其余功能一致。
