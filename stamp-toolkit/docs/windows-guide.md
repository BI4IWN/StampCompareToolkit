# Windows 版安装与使用

> 版本：v3.6.8 ｜ 适用系统：Windows 10 / 11（64 位）

印章比对工具（Stamp Compare Toolkit）桌面版在 Windows 上提供两种分发形式，功能与 macOS 版一致（唯一差异见「平台差异」）。

---

## 一、安装包

| 文件 | 说明 | 适用场景 |
|---|---|---|
| `印章比对工具 Setup 3.6.8.exe` | NSIS 安装向导，可选安装目录，创建开始菜单/桌面快捷方式 | 长期使用、需要卸载项 |
| `印章比对工具 3.6.8.exe` | 免安装单文件，双击直接运行 | 临时使用、U 盘携带、无管理员权限 |

- 体积约 180 MB（内含 Python 运行时与 OCR 引擎，**无需另装 Python**）。
- 首次运行会解包到临时目录，启动约 3–10 秒。
- 程序未做代码签名，Windows SmartScreen 可能提示「已保护你的电脑」→ 点「更多信息 → 仍要运行」。

## 二、系统要求

| 项目 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10 22H2（64 位） | Windows 11 |
| CPU | x64 双核 | 四核及以上 |
| 内存 | 4 GB | 8 GB+ |
| 磁盘 | 1.5 GB 可用 | 2 GB+ |
| 显示 | 1280×800 | 1440×900 及以上 |

## 三、首次启动

1. 双击安装包完成安装（或直接运行免安装版）。
2. 程序会在本机启动一个后端服务并把界面加载进来，右上角显示后端版本号即表示就绪。
3. 状态栏提示「OCR 模型加载中（首次约 10–30 秒）」——首次加载完成后，之后启动只需 1–3 秒。
4. 拖入（或 `Ctrl+V` 粘贴）两枚印章图片 → 自动提取、自动对齐 → 右侧显示判定/识别/候选。

## 四、数据与目录

| 内容 | 位置 |
|---|---|
| 设置（快捷键、印章库路径、主题） | `%APPDATA%\印章比对工具\settings.json` |
| 印章库索引 | 取决于设置中的「印章库路径」，默认 `%USERPROFILE%\印章库` |
| 本地 AI 引擎（Windows 不支持，见下） | `%APPDATA%\印章比对工具\engines\` |
| 后端日志 | 程序窗口内「使用说明 → 关于」可见版本与路径 |

卸载程序**不会**删除印章库与设置；需要彻底清理时手动删除上述目录。

| 操作 | 快捷键 |
|---|---|
| 全局截图（选区后直接贴入） | `Ctrl+Shift+S`（可在「设置」中修改） |
| 打开图片 | `Ctrl+O` |

## 六、平台差异

| 能力 | macOS | Windows |
|---|---|---|
| 本地视觉大模型（PaddleOCR-VL，MLX 加速） | ✅ 可选安装（约 1.5 GB） | ❌ 不可用（依赖 Apple Metal/MLX） |
| RapidOCR（内置，免安装） | ✅ | ✅ |
| 印章库名称匹配（Top-3 候选） | ✅ | ✅ |
| 云端视觉识别（DeepSeek / 智谱 / 火山方舟豆包 / 自定义） | ✅ | ✅ |
| 圆章校正（椭圆 → 正圆） | ✅ | ✅ |
| 黑/灰章与淡色章取色、剔除、放大镜 | ✅ | ✅ |
| 全局截图快捷键 | ✅ | ✅ |

> Windows 上「⋯ 更多 → 识别引擎…」会显示「当前平台不支持本地视觉模型」，识别自动走 RapidOCR + 印章库匹配；如需更高识别率，请在「AI」中配置云端视觉模型。

## 七、常见问题

**1. 启动后界面一直显示「正在检测 OCR 服务…」**
后端启动失败或被占用。检查是否有其它程序占用 `8799` / `18799` 端口：
```bat
netstat -ano | findstr "8799 18799"
```
结束占用进程后重启程序。

**2. 首次识别很慢（20–40 秒/张）**
首次会加载 OCR 模型（10–30 秒）；之后单张约 1–5 秒。若长期很慢，检查是否被杀毒软件实时扫描拖慢（可将安装目录加入白名单）。

**3. 提取结果为空白**
章不是红色/黑色（例如蓝色章）→ 在「⋯ 更多 → 墨色」中选「蓝」，或用「点选取色」在章上点一下；淡色章会自动启用淡墨提取，也可手动加色。

**4. 章被拍歪了、边不重合**
默认开启「圆章校正」（⋯ 更多 → 圆章校正）。若识别成异形章，可关掉该开关或先用「框选区域」只框章体。

**5. 想换端口 / 不想自动打开浏览器**
后端支持 `--port 8765`、`--no-browser`、`--no-ocr`、`--no-engine` 参数，桌面版由外壳自动管理，一般不手动传参。

## 八、构建说明（开发者）

在 macOS 或 Windows 上均可交叉构建 Windows 包（无需 Wine）：

```bash
cd desktop
npm install
npx electron-builder --win nsis portable --x64
```

产物：
- `desktop/dist/印章比对工具 Setup <版本>.exe`（安装器）
- `desktop/dist/印章比对工具 <版本>.exe`（免安装）
- `desktop/dist/win-unpacked/`（解包目录，便于排查）

前置条件：
- `desktop/runtime/python-win-x64/` 存在且包含 `python.exe`、`rapidocr_onnxruntime`、`onnxruntime`、`opencv`、`numpy`、`Pillow`（已随仓库本地保留，不入库）；
- `stamp-toolkit/` 通过 `extraResources` 打进 `resources/stamp-toolkit`；
- 构建后可用 `desktop/dist/win-unpacked/resources/runtime/python-win-x64/python.exe` 体积校验（约 450 MB）。
