# 印章对比工具 (Stamp Compare Toolkit) v2.3.0

一款面向法务合规与文档核验场景的本地印章对比工具，支持将单据印章与合同印章进行可视化对比和文字识别。

开发者：李劲松 (BI4IWN)

## 功能特性

- **智能印章提取**：自动检测印章区域并归一化为标准圆形，支持异形章与**圆环缺口/断笔的残缺圆章**识别，提取输出 **1200×1200 高分辨率**保持墨迹清晰
- **墨色多选**：默认红章，可叠加选择红 / 蓝 / 紫多种墨色同时提取（混合盖章场景一网打尽），切换后自动重新提取
- **💧 手工取色与剔除（每枚印章独立，含颜色排除）**：参考章与待验章各有独立的墨色面板（位于各自提取区上方），预设红/蓝/紫多选 + 在原图预览上点选任意墨色（支持多种、芯片色点展示），× 剔除不需要的颜色，按该印章的选择实时重新提取，互不影响
- **颜色排除**：每个自选色可标记为「提取」（保留）或「排除」（去除），排除色优先——印章提取时把所选排除色的像素剔除（如去除背景色、误捕捉的杂色），点选颜色后在芯片上即可切换
- **单章即显示**：加载第一枚印章后对比区域立即显示提取结果，可先行人工查验，无需等两枚齐全
- **多印章候选**：一张图检出多个印章时提供候选切换芯片，单据上的公章 / 财务章可分别提取对比
- **一键自动对齐**：质心对齐 + RMS 半径归一 + 角度直方图圆相关 + IoU 精调，自动计算旋转 / 缩放 / 偏移（快捷键 `A`），对齐后即时给出相似度与差异提示
- **三种对比模式**：叠加模式（双色叠印）、滑块模式（左右分割对比）、并排模式（等大并列展示）
- **差异高亮**：像素级对比两枚印章，绿色表示吻合、红色表示偏差，实时计算相似度百分比（带结果缓存，交互流畅）
- **交互微调**：旋转、缩放（等比/水平/垂直独立调节）、偏移、拖拽，精确对齐两枚印章
- **放大镜**：4 倍局部放大，配合高分辨率提取可检查笔画级细节
- **OCR 文字识别**：集成 PaddleOCR 后端，自动识别印章公司名称、编码和类型，兼容 PaddleOCR 2.x / 3.x，支持多墨色识别
- **对比报告导出**：一键生成自包含 HTML 报告（内嵌图片、相似度结论、OCR 对照表、时间戳），适合核验留痕归档
- **PNG 导出**：将当前对比画面导出为 PNG 图片
- **纯本地运行**：所有数据处理均在本地完成，不上传任何信息

## v2.7.0 更新日志

**新增 / 改进**

- **可在已提取印章图上取色**：进入取色模式后，除原图预览外，还可在提取结果缩略图上直接点选颜色（透明区域自动忽略），便于在去除背景后的纯净印章上精确取色
- **提取/排除以最后操作为准**：同一颜色先提取后排除（或反之），按最后一次操作切换其"提取/排除"状态，不再产生重复项
- **修复连续取色/排除时卡顿、无法选中颜色**：① 重提取改为防抖合并（连续点选只触发一次）；② 形态学膨胀由 O(N·r²) 暴力循环优化为 O(N·r) 可分膨胀，重提取提速数十倍，主线程不再长时间阻塞
- 自选色芯片重新显示颜色色点（背景色=选定颜色），并保留十六进制编码

## v2.6.0 更新日志

**新增 / 改进**

- **手工取色覆盖默认墨色**：首次点选手工颜色（提取或排除）时，自动取消默认红章，仅按手工选择的颜色提取（不再叠加默认色）；移除所有手工颜色后自动恢复默认红章
- **提取结果支持缩放**：点击提取缩略图可在 1× ↔ 2× 之间切换；对比区缩放范围由 30%-200% 扩大到 20%-400%
- **修复排除黑色无法提取印章**：排除色改为"色相+饱和度+亮度"综合匹配，正确区分黑色（无彩色，hue 0）与红色（彩色，hue 0），排除黑色不再误伤红章；排除色允许选取黑色/深色（此前被"饱和度过低"校验拒绝）

## v2.5.0 更新日志

**新增 / 改进**

- **颜色排除功能**：自选色新增「提取 / 排除」两种模式（面板新增「⊘ 排除」取色按钮，芯片可一键切换）。排除色优先——印章提取时命中所选排除色的像素被剔除，用于去除背景色或误捕捉的杂色
- **修复排除后无法提取印章**：排除色改用收紧的独立容差（前端 ±6°、后端 ±8°），只剔除贴近所选颜色的像素，不再因容差过宽误伤整枚印章
- **修复无法选择多个颜色**：相近颜色点选改为「重新启用」而非静默跳过；提取 / 排除两种模式均可连续点选多种颜色
- **修复点选后颜色未选中的问题**：取色改为在点击瞬间实时采样原图像素，并修正边缘采样越界（此前依赖悬停缓存 + 边缘越界会取到错误颜色）
- 排除色同时贯通前端检测/提取与后端 OCR（`/ocr` 新增 `excludes` 参数）

## 快速开始

### 方式一：一键启动（推荐）

**macOS（推荐）：**

直接双击 `启动印章对比工具.command` 即可运行（.command 扩展名会被 macOS 自动用「终端」打开，无需任何设置）。

> 说明：双击 `launcher.sh` 在部分 macOS 上会打开文本编辑器（系统将 .sh 关联到文本编辑），属正常现象；请改用 .command 文件，或右键 `launcher.sh` → 打开方式 → 终端.app。

**Linux：**

```bash
chmod +x launcher.sh
./launcher.sh
```

**Windows：**

双击 `launcher.bat`

启动器会自动完成以下工作：

1. 检测 Python 3 环境，缺失则提示安装
2. 检测并安装 PaddlePaddle、PaddleOCR、OpenCV 依赖
3. 启动本地 HTTP 服务（端口 8765）
4. 自动打开浏览器访问工具页面

> 常用参数：`./launcher.sh --port 9000` 更换端口；`./launcher.sh --no-install` 跳过依赖安装（依赖已就绪时启动更快）；`./launcher.sh --no-browser` 不自动打开浏览器；`python3 stamp_app.py --no-ocr` 跳过 OCR 模型加载（仅使用对比功能）。
>
> 依赖安装说明：首次运行时，若系统 Python 缺少 OCR 依赖，启动器会创建 `.venv` 虚拟环境并把 PaddlePaddle / PaddleOCR / OpenCV 安装到其中（约 700MB，需几分钟）。虚拟环境位于 `src/.venv`，已在 `.gitignore` 中排除。

### 方式二：手动启动

如果只需要印章对比功能（不需要 OCR），可以直接用浏览器打开 `stamp-compare.html`：

```bash
# macOS
open stamp-compare.html

# Linux
xdg-open stamp-compare.html

# Windows
start stamp-compare.html
```

### 方式三：命令行启动完整服务

```bash
# 安装依赖
pip install paddlepaddle paddleocr opencv-python

# 启动服务
python3 stamp_app.py              # 默认端口 8765
python3 stamp_app.py --port 9000  # 自定义端口
python3 stamp_app.py --no-ocr     # 跳过 OCR 模型加载，启动更快（仅对比/导出）
```

## 环境要求

- **操作系统**：macOS、Windows、Linux
- **浏览器**：Chrome、Safari、Firefox、Edge 等现代浏览器
- **Python**：3.8+（仅 OCR 功能需要）
- **Python 依赖**（仅 OCR 功能需要）：
  - PaddlePaddle（~700MB）
  - PaddleOCR

> 注意：即使不安装 Python 和 OCR 依赖，印章对比、差异高亮、导出等核心功能仍可正常使用。

## 使用流程

1. **加载图片**：通过粘贴（Ctrl+V）、拖拽或点击上传，分别加载参考章和待验章图片
2. **自动提取**：工具自动检测印章区域（按墨色模式）并提取归一化；一图多章时通过候选芯片切换
3. **一键对齐**：点击「⚡ 自动对齐」（或按 `A`）自动完成旋转/缩放/偏移对齐
4. **选择对比模式**：叠加 / 滑块 / 并排，快捷键 1/2/3 切换
5. **微调（可选）**：如需更精细的对齐，使用工具栏滑块或鼠标交互调整
6. **差异分析**：开启差异高亮查看像素级对比结果和相似度
7. **OCR 识别**（可选）：点击"全部识别"提取印章文字信息
8. **导出结果**：点击"导出"保存对比画面 PNG，或点击"报告"生成归档用对比报告

详细操作说明请参阅 [操作手册](docs/operation-manual.md)。
